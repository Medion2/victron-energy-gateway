# Changelog

## 1.0.0 - Public release

Based on the proven local V1.3.4 installation.

- removed site-specific IP addresses and identifiers
- DHCP enabled by default
- generic hostname and MQTT client ID
- SML OBIS parsing for import/export energy and total/L1/L2/L3 power
- Victron `pvinverter` MQTT integration
- automatic device re-registration
- fixed 230 V phase display
- calculated phase and overall current
- web dashboard
- Wi-Fi fallback
- web OTA
